# law-firm-theme-2

Harlan & Voss law firm website, published with GitHub Pages.

Live site: https://SaadWebsites.github.io/law-firm-theme-2/

This repository holds the built site. Page sources live in the project workspace under `themes/theme-2/_content/` and `themes/theme-2/_gen/`. Edit those, run `node _gen/run.cjs` then `node build.cjs`, and redeploy.
